## 3. 编译

环境：TeX Live 2026（含 XeLaTeX、ctex、fandol 字体）。

```bash
# 方式一：latexmk（按模板 .latexmkrc 输出到 build/）
latexmk full.tex

# 方式二：直接 XeLaTeX（需两遍，第二遍生成“共 N 页”）
xelatex full.tex
xelatex full.tex
```

本次交付的 `build/full.pdf` 与 `build/full.log` 即用 `xelatex` 连续编译两遍得到；日志中无错误、无缺字、无 Overfull 警告。

## 4. 版式规则落实

| 规则 | 实现 |
|---|---|
| 每页一道主观题 | 每道主观题单独使用一个 `qitems` 环境，环境结束即 `\clearpage`；经 `.aux` 标签核对，106 道主观题各占一页，无同页重复。 |
| 小问同页 | 小问保留在题干的同一 `qitems` 内，不插入分页（如第 9 章第 7 题 (1)(2)(3) 同页）。 |
| 主观题优先同页 / 超页标注 | 主观题答题区 8 cm，全部题目均在一页内完成；本次无跨页，故正文未出现【跨页】。`\crosspage` 命令已在导言区定义，供后续增补题目使用。 |
| 客观题连续排版 | 选择题、填空题按原顺序放在同一个 `qitems` 中连续排版，不强制一页一题。 |
| 主观题前后分页 | 客观题 `qitems` 结束即清页；主观题每题结束即清页，因此主观题所在页只有该题。 |
| 答案 / 解析 | 原 PDF 中无答案、无解析，故未生成答案页（全篇检索“答案/解析”仅命中“答案可能不止 1 个”这一指导语）。 |
| 固定高度答题区 | 导言区定义 `\answerarea[高度]`，默认 8 cm；客观题用 3.5 cm，主观题用 8 cm。用法示例：`\answerarea[5cm]`。 |
| 题号、章节、指导语 | 保留原章名（章内自动编号已用 `notocnum` 关闭，避免“第1章 第一章”重复）、原节名“一、多重选择题（答案可能不止 1 个）”等、原题号及题号后的 `*`。 |
| 页眉页脚 | 使用模板 `fancyhdr` 设置，页眉为“工程光学自测练习做题本”，页脚“第 N 页 / 共 241 页”。 |
| 封面 / 目录 | 按任务要求不生成，未调用 `\maketitle`、`\tableofcontents`。 |

- **表格**：第 204 页第 23 题的选择填空表已用 `tabularx` 重排为 LaTeX 表格。
- **内嵌题干**：第 58、59、60、112 页的题干原本是图片，已人工转写为文字，并在正文标注【待确认】。
- **原文用字**：保留原题措辞与顺序，未改题、未补题；“慧差”等原文用字未作规范化。

## 7. 模板一致性

- `ExBook.cls` 与模板目录中的文件逐字节一致，未修改。
- 文档类选项：`\documentclass[standard, analysis, notocnum]{ExBook}`。其中 `standard`、`analysis` 沿用模板示例；`notocnum` 仅关闭自动章节编号，使“第一章”“一、”等原编号按原文显示，不改变页面布局。
- 新增命令只有 `\answerarea`（答题区）、`\crosspage`（跨页标记）、`\tbd`（待确认标记），均为排版辅助命令，不改模板样式。
- `config.tex` 仅把页眉文字改为本书名；主题色、页脚、字体等保持模板默认。

## 8. 已知限制

- 公式为规则化转写，不是逐字符 OCR；极少数多字母下标（如 `l_F2`、`n_D`、`ν_D`）按上下文还原，建议对照原 PDF 复核（清单中已列）。
- 原 PDF 的题图多为 300 dpi 位图，按最大宽 14.6 cm、最大高 9.2 cm 等比缩放；个别图内小字可能偏小。
- 原 PDF 每页大量留白，本重排按“客观题连续、主观题一页一题”执行，空白量与原书不同。
