# 横版 Pad 版说明（`full[pad]`）

## 1. 版本定位

- 文档类：`\documentclass[padl, analysis, notocnum]{ExBook}`。
- 版面：**200 mm × 150 mm 横版**（4:3），适合平板阅读与手写批注。
- 源文件与排版内容同 A4 版 `full.tex`，仅版式、答题区和图片缩放不同。
- 输出文件名后缀为 `[pad]`：`full[pad].tex`、`build/full[pad].pdf`、`build/full[pad].log`。

## 2. 版式与分页

- **每题一页**：346 道题对应 346 页，经 `.aux` 标签核对，每页恰好一道题，无同页重复、无跨页。
- 章、节标题与该节第一题同页；不另加封面、目录。
- 页眉为 0.8 cm 主题色顶栏：左侧书名，右侧页码“第 N 页 / 共 346 页”。
- 模板自带的 `padl` TikZ 顶栏在当前 TeX Live 2026 / fancyhdr 5.2 下会被裁切，因此在本文件内用等效 TikZ 顶栏重绘；`ExBook.cls` 未修改。

## 3. 答题区

统一使用 `\answerarea[高度]`，按题型与页面余量取值：

| 题型 | 答题区高度 |
|---|---:|
| 客观题（无图） | 4.0 cm |
| 客观题（有图） | 1.6 cm |
| 主观题（无图） | 最多 7.0 cm，按题干长度自动收缩 |
| 主观题（有图） | 2.4 cm（个别长题 2.0 cm） |
| 第 204 页表格题 | 1.2 cm |

答题区上下各有一条浅色细线，中间为空白书写区；高度可通过 `\answerarea[6cm]` 单独调整。

## 4. 图片与表格

- 37 个题图沿用 `figures/` 中的原图。
- 横版页高有限，图片按**最大宽 16.2 cm、最大高 4.2 cm** 等比缩放；带图题根据题干长度进一步压缩图高。
- 第 204 页表格改用 `\small` + `tabularx` 重排，控制在半页内。
- 第 281 页公式与图片同页排版。

## 5. 编译

环境：TeX Live 2026 + XeLaTeX。

```bash
xelatex "full[pad].tex"
xelatex "full[pad].tex"
```

文件名中的方括号可直接使用；两遍编译后页码“共 346 页”才正确。也可用：

```bash
latexmk "full[pad].tex"
```

本次交付的 `build/full[pad].pdf` 与 `build/full[pad].log` 即两遍 XeLaTeX 的结果，日志无错误、无缺字、无 Overfull。

## 6. 内容一致性

- 题号、题干、选项、填空、公式、图片、表格与 A4 版一致；未改题、未补题。
- 答案/解析：原 PDF 没有，横版同样不生成。
- 4 处据图转写题仍标【待确认】，详见 `../待确认清单.md`（与 A4 版共用）。
- 原 PDF 无跨页题，横版经版面压缩后仍保持每题一页，因此正文无【跨页】标记。

## 7. 与 A4 版的差异

| 项目 | A4 版 `full.tex` | 横版 `full[pad].tex` |
|---|---|---|
| 纸张 | A4 纵向 | 200×150 mm 横向 |
| 分页 | 客观题连续排，主观题一页一道 | 全部题目一页一道 |
| 页数 | 241 | 346 |
| 图片高度 | 最大 9.2 cm | 最大 4.2 cm |
| 答题区 | 客观 3.5 cm，主观 8 cm | 见上表，按题型与余量 |
| 页眉 | fancyhdr 文本页眉 | TikZ 主题色顶栏 + 页码 |
